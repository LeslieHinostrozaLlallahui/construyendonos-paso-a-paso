Detrás de las palabras

Hola, soy Leslie.

Construyéndonos nace de una idea sencilla: podemos aprender durante toda la vida y mirar nuestra realidad con curiosidad, pensamiento crítico y esperanza.

Este es un espacio personal para compartir ensayos, explorar datos, hacer preguntas y conectar las experiencias cotidianas con temas más amplios: la educación, el trabajo, las finanzas y el desarrollo personal.

Publicaré un ensayo cada semana. No para tener la última palabra, sino para abrir una conversación y seguir aprendiendo en el camino.
